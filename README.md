# Smart Attendance System

A real-time attendance system that automates student tracking using face detection.  
This project leverages **Python, OpenCV, and Haar Cascade Classifier** to identify students from a live video feed and mark their attendance automatically.

## Features
- Real-time face detection using OpenCV
- Automated attendance marking (reduces manual effort)
- Uses Haar Cascade Classifier for fast and efficient face detection
- Attendance logs stored for future reference

## Tools & Technologies
- Python 3.x
- OpenCV
- Haar Cascade Classifier
